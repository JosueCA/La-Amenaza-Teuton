# Imperivm 1 HD

- Descargar en https://github.com/JosueCA/La-Amenaza-Teuton/releases

Migrados cambios desarrollados para el mod "La Amenaza Teutón" a la versión base de Imperivm 1

Solo para Imperivm 1 La Guerra de las Galias 1.13 o 1.16 (No compatible con Celtic Kings)

- Soporte hasta resoluciones 1920px
- Ajustados cmdbars para resoluciones 1920px
- Convertidos archivos de audio para mayor compatibilidad Wine
- Una vez instalado no es necesario disco para jugar
- La interfaz del menú de inicio tiene dimensiones estáticas, no ajustadas para resoluciones 1920px (no afecta al juego)
