# Añadidas resoluciones al fichero VXCONST.INI

* Usar data_13_hd.pak para la versión del juego 1.13
* Usar data_16_hd.pak para la versión del juego 1.16

1) Copia de seguridad del data.pak actual
2) Copiar data_13_hd.pak o  data_16_hd.pak como data.pak, reemplazando el existente
